## 🚀 Projetos em Destaque

### 🏙️ UrbanEdge Data Lakehouse Pipeline
Pipeline de dados completo com arquitetura **Bronze / Silver / Gold**, modelado em BPMN 2.0 e implementado em Python. Inclui validação rigorosa contra literatura académica e geração programática de XML BPMN.

### 🗄️ Lambda Architecture com Sakila DB
Laboratório prático de arquitetura Lambda para Data Lakes — ingestão via **MQTT**, processamento em Python, e armazenamento numa base de dados PostgreSQL Sakila. Inclui subscriber script `mqtt_bronze_ingestion.py`.

### 🔬 Geração de Dados Sintéticos
Exploração avançada de técnicas de síntese de dados com **Decomposição de Cholesky**, **cópulas estatísticas**, **SDV/CTGAN** e **redes bayesianas** para preservar correlações multivariadas.
